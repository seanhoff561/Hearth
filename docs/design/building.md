# Building and structure

*Status: planned (V2-8). Pieces started in V2-0 (`construction/`).*

## Planned model
Construction pieces made of materials (posts, beams, wattle, thatch, stone courses…) with
joints; construction stages; an incremental stability solver (support propagation first, then a
load/span check using material strengths) that runs off the main thread with a budget; collapse
into physical debris; excavation supports; rain shedding by pitch and material; rot in ground
contact; shelter quality for the body model; a builder's view showing stress.
